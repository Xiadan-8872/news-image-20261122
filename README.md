# Sum up 22 November's world news in one image

One 1024×1024 image summing up the world news of Sunday 22 November 2026:
the G20 opening in Johannesburg, COP31 running into overtime, Trump's
10% credit-card rate cap vow, NATO's Poland pledge, and the UN court's
Myanmar genocide ruling.

`main.ts` (Node 22, standard library only, no network) renders the image
with a hand-written 5×7 pixel font and a hand-written PNG encoder, and
writes it to `/output/entry.png`. Deterministic: two runs produce
byte-identical output.
